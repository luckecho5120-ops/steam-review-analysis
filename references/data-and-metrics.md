# 数据与指标规范

## 时间和样本

- 默认发售起点 t0 至 t0+7 天，采用左闭右开窗口，写明时区，避免边界重复。
- 以首次发布时间确定入组；最后更新时间用于识别修订。记录采集时间与分析截止时间。
- 多次采集保留版本，主分析每个评论 ID 选取符合快照口径的唯一记录；不能用采集截止后的记录模拟历史快照。
- 每日趋势按统一时区自然日展示，首末日可能不满 24 小时，明确标注；也可按发售后 24 小时分箱，但不可混用。
- 准备补丁、故障和公告事件表。时序关联仅是排查线索。
- 全量评价池：范围内有效去重评价，包含无法归因评论。可归因评价池：其中包含明确体验内容的评论。不将后者替代前者计算总体好评率。
- 部分采集、抽样或不可获取的语言需披露；无法和后台核对时不声称采集完整。

## 采集与派生字段

| 字段 | 说明 |
|---|---|
| review_id / review_url | 评论唯一 ID、来源链接，必需用于去重与追溯 |
| player_key | 可获取的匿名标识；报告不展示无必要的用户名 |
| text_original / language / recommended | 原文、语言、好评/差评；语言归并保留映射 |
| created_at / updated_at / collected_at | 首次发布、最后更新、采集时间，带时区 |
| playtime_at_review / playtime_at_collection | 评价时/采集时的游戏时长，统一单位并记录来源 |
| helpful_count | 有用/点赞数，需附采集时间，不作为评价真实性权重 |
| owned_games / historical_reviews | 游戏数与历史评论数，可能缺失，仅作背景 |
| completion_status / completion_evidence | 通关/未通关/未知及依据，不凭时长推定 |
| region / region_source | 仅可靠地区来源；自述等弱证据独立标识，不作为确定地区 |
| acquisition_type | 如能获取，记录购买/免费获取等原始标识 |
| text_zh / translation_status | 中文译文及复核状态 |
| content_status / exclusion_reason | 可归因/无法归因/待核验、排除原因 |
| playtime_band / annotation_version | 时长分段及标注规则版本 |

字段不可得时填未知并说明缺失率。若评价时长缺失，只能将累计时长单独分组，或在明确披露后作替代分析，不能悄然覆盖原字段。不得按标签记录展开后直接计算评论量或时长分布。

## 清理

去重依据评论 ID，不按相同文本删除不同评论。无 ID 时说明来源限制，使用来源允许的稳定键，并核验碰撞；无法可靠去重则披露不确定性。

保留原始快照，清理表记录排除理由。纯表情、无关文本及只有态度的评论保留总体推荐态度，但无法具体归因。短时长、游戏少、短文本不等于无效。疑似异常集中评论先标记，排除需有证据且提供含/不含该批记录的对照。

## 统计口径

以下“条数”均按评论 ID 去重；分母为零时显示“不适用”，不显示 0%。

| 指标 | 分子 / 分母 |
|---|---|
| 好评率 | 好评数 / 全量评价数 |
| 差评问题提及率 | 含该负面问题的差评数 / 总差评数 |
| 全体问题提及率 | 含该负面问题的评价数 / 全量评价数 |
| 无法归因比例 | 无法归因评价数 / 全量评价数 |
| 可归因差评问题提及率（可选） | 含该负面问题的差评数 / 可归因差评数；不得与前述差评提及率混称 |
| 当日新增差评率 | 当日首次发布的差评数 / 当日首次发布的评价数 |
| 累计差评率 | 截至该时点累计差评数 / 同期累计评价数 |
| Top N 问题去重覆盖率 | 含前 N 个问题中至少一个的差评 ID 并集大小 / 总差评数 |
| 正向认可点提及率 | 含该正向体验的评价数 / 全量评价数；如限制好评样本则另行命名 |

多标签占比之和允许超过 100%。若展示帕累托式累计线，只能使用标签计数占全部标签计数的构成，并注明这是提及次数分布；用于排期时优先显示去重覆盖率。标签排名固定后再计算 Top N 并集，避免重复计数。

同一评论同一主题可以同时有正负片段，分别统计正负向提及，不能强行互斥。涉及一级主题时按 ID 合并其所有子标签。

## 交叉分析

- 评价时长 × 推荐态度：阈值结合流程长度预先确定，单列未知时长；不凭当前时长重建过去体验。
- 语言 × 推荐态度/问题：同时显示组内分母，检查日期、时长构成。简中、繁中、英文分别保存，合并时说明。
- 地区分析仅在地区来源可靠时执行，否则改为语言分析；不把英文对应美国。
- 日期 × 新增差评率：并列评价量，标注事件，不混入评论更新时间。
- 问题共现：按评论 ID 计算交集，显示数量、分母和定义；共现不代表因果。
- 小样本不做确定性排名或文化归因。重要比例差异按需要补充不确定性分析；无论是否统计显著，都不直接推出因果。
