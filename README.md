# Steam 评论分析 Skill

将 Steam 玩家评价转化为可追溯的体验洞察，以及产品、社区和宣发行动清单。默认分析正式发售后首周，也支持指定周期和已有评论数据。

## 能力

- 固定采集窗口、快照状态、来源与字段缺失口径。
- 清理去重、中文翻译与游戏术语统一。
- 按语义片段提取正向认可点和负面问题，执行两级多标签标注。
- 按评价时游玩时长、通关状态和语言等独立维度分群。
- 计算好评率、问题提及率、Top N 问题去重覆盖率及口碑趋势。
- 输出可复核的分析报告、优先级和行动复查计划。

## 安装

将本仓库目录放入本机 Codex 的 skills 目录，并保持目录名为 `steam-review-analysis`。目录内须直接包含 `SKILL.md`、`agents/` 和 `references/`。默认位置为 `~/.codex/skills/steam-review-analysis/`。

## 调用示例

```text
使用 $steam-review-analysis 分析这份 Steam 首周评论，输出核心认可点、主要问题和 Top 3 行动建议。
```

```text
使用 $steam-review-analysis 审核这份 Steam 评价分析 SOP，说明口径不清和可能导致误判的地方。
```

提供已有评论文件，或说明游戏、分析周期和可用数据来源。数据采集能力取决于运行环境中的工具、权限和来源可用性；本仓库不包含 Steam 抓取器。

## 核心分析约束

不因短时长或游戏数量少删除评价；不以语言替代国家；不将多标签占比直接累加为玩家覆盖率；不把问题提及或时间关联视为已确认因果。所有结论应保留来源、样本量和统计分母。

仓库仅包含技能说明和模板，不包含玩家评论数据、账户凭据或内部业务数据。
